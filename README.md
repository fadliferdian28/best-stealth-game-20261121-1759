**Lantern Rock** — a top-down stealth game set on a lighthouse island at night. You are a night salvager: steal the keeper's prize from each of three zones and reach the boat unseen, past lampwarden patrols with occluded vision cones, sweeping cameras and tripwire lasers. The signature mechanic is the rotating lighthouse beam — standing in it makes you visible even in shadow, so every crossing is timed to the sweep. Sneak, sprint, hide in scrub and barrels, and toss coin lures to pull wardens off their routes. Pure HTML5 canvas + vanilla JS, zero dependencies, all art drawn in code and all sound synthesized with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests.
